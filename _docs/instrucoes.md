# Objetivo

Um site PWA que deve se comportar como um app hibrido feito em Astro.JS para rodar em um worker no Cloudflare. A temática do APP é finanças no contexto de economia em "52 semanas" - ou seja, o app vai entrar em contato com o usuário com lembretes semanais para que o usuário salve o dinheiro cadastrado por ele para atingir determinado objetivo. No momento do cadastro da meta o app deve informar o quanto deve ser guardado semanalmente ou mensalmente para atingir o valor do objetivo que está sendo cadastrado. O usuário pode cadastrar mais de um objetivo. O site deve usar tailwind para css, alpinejs para responsividade e htmx para lidar com o restante. O site precisa ter um seletor de idiomas e deve ter 3 logo de inicio: pt-br, en-us e es-es.

# Requisitos

- Apague todo o conteúdo do repositório e crie pastas separadas para cada assunto: Frontend + Monitoring. 
- No frontend, toda mudança de página precisa ter transição para simular a experiência de aplicativos, precisa ter suporte a swipe left e right também. Use as APIs Web e pacotes necessários. 
- Sincronize o site local com o banco D1 do cloudflare, faça cada update estar salvo em um localStorage ao mesmo tempo que salva no D1.
- Use uma camada de cache KV também. A ideia é: consulta local + consulta KV + consulta D1.
- Crie uma com todas as moedas do mundo para criar o dropdown de selecao de moedas no onboarding.
- Faça todos os commits e documentações em ingles. 
- Desenha o banco de dados e me mostre para aprovaçao. 
- O visual, tipografia e o tom de comunicação pode seguir a referencia da img1.png

# Fluxo do Worker de Monitoramento
Na pasta monitoring crie um worker schedulado que rode todo dia a meia noite de UTC-0. Ele deve navegar pela tabela de projetos para verificar qual é a proxima data de expiração de cada investimento. Para todos os projetos que estiverem com a data de investimento expirada e não completa deve enviar um push notification e um email para o dono projeto. Deixe o template de ambos em arquivos separados para ser mais facil de editar. 

# Dependencias

Use astro build 6+ para hospedar no cloudflare worker. Use better auth para login social, AWS Cognito para integração do login, AWS SNS para push notification e AWS SES para envios de email.
